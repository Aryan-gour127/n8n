 10 Basic AI n8n Automation Workflows

Beginner-friendly starter templates for learning AI automation with n8n.

## Included
1. AI PDF Summarizer
2. AI Email Reply Assistant
3. AI YouTube Summarizer
4. AI News Digest
5. AI Resume Analyzer
6. AI Chatbot with Memory Starter
7. Basic RAG Document Chat
8. AI Social Media Content Generator
9. AI Website Content Summarizer
10. AI Lead Qualification Assistant

## Important
These are **starter learning templates**, not copies of third-party community workflows.
Some nodes require credentials or an external service. Configure credentials after import.
Review every workflow before activating it.

## Import
In n8n:
**Workflows → Import from File → select the `.json` file**
